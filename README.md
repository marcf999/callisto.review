# callisto.review

Peer Review of the Project Callisto Reports on Cold Fusion.

- `index.html`: landing page
- `review.html`: full text of the review
- `CALLISTO_PEER_REVIEW.pdf`: the review as a PDF
- `enea.png`: photograph used in section 2
- `CNAME`: custom domain for GitHub Pages (callisto.review)

Static site, no build step. Served by GitHub Pages from the `main` branch root.
